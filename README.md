# EventAura — Responsive Event Management Website

A front-end event discovery and registration website built using HTML5, CSS3 and vanilla JavaScript.

## Features
- Responsive homepage and navigation
- Upcoming event cards with images, dates, venues and descriptions
- Search and category filtering
- Event detail popup
- Registration form with JavaScript validation
- Confirmation notification
- Local Storage registration demo
- Dark/light mode
- Countdown timer

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — event data and interactive functionality
- `Project_Report.docx` — project explanation and implementation
- `SUBMISSION_CHECKLIST.txt` — final submission checklist

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the Live Server extension by Ritwick Dey.
3. Right-click `index.html` and choose **Open with Live Server**.

## Deployment
Upload the project to GitHub Pages or drag the folder contents into Netlify's manual deploy area.

## Note
Registration details are stored only in the current browser's Local Storage. This is a front-end demonstration, not a production backend or shared database. Edit the `events` array in `script.js` to customize event content.
